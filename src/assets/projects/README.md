# Prévias dos projetos

Coloque aqui uma imagem ou GIF por projeto. O nome do arquivo precisa ser o `id` do projeto:

| Projeto | Arquivo | O que mostrar |
|---|---|---|
| ProcessFlow | `processflow.webp` | Terminal executando tarefas em processos filhos |
| Automação contábil | `automation.webp` | Planilha do Livro Diário gerada, sem dados reais |
| BombermanCLI | `bombermancli.webp` | Uma partida com jogador, bombas, blocos e inimigos |
| FinanceFlow | `financeflow.webp` | Dashboard com resumo do mês e gráficos, com dados fictícios |

- Formatos aceitos: `.webp`, `.png`, `.jpg`, `.jpeg` e `.gif`.
- Proporção 16:9, por exemplo 1280x720. Outras proporções são cortadas para preencher o espaço.
- O card detecta o arquivo sozinho no build. Sem arquivo, ele aparece sem imagem.
- O texto alternativo fica em `previewAlt`, no objeto `copy` de `src/App.jsx`. Ajuste se a imagem mostrar outra coisa.
